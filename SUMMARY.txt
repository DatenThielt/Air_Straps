MOST CRITICAL BREAKING CHANGES:
================================

1. Item Registration
   OLD: RegistryEvent.Register<Item> event handler
   NEW: DeferredRegister<Item> with RegistryObject<Item>
   Impact: COMPLETE rewrite of registration pattern

2. Item Constructor
   OLD: Multiple setter methods
   NEW: Item.Properties builder pattern
   Impact: Constructor signature changes completely

3. Item Usage Method
   OLD: onItemRightClick(World, EntityPlayer, EnumHand)
   NEW: use(Level, Player, InteractionHand)
   Impact: Method rename + parameter changes + return type

4. Model Registration
   OLD: ModelRegistryEvent + ModelLoader.setCustomModelResourceLocation()
   NEW: Automatic from JSON (delete entire class)
   Impact: DELETE entire ModelRegistryHandler.java

5. Mod Initialization
   OLD: @Mod class annotation + @EventHandler
   NEW: mods.toml + @Mod.EventBusSubscriber + @SubscribeEvent
   Impact: Change from class-level to separate handlers

6. Event Handling
   OLD: @Mod.EventBusSubscriber(Side.CLIENT)
   NEW: @Mod.EventBusSubscriber(..., bus = Bus.FORGE, value = Dist.CLIENT)
   Impact: All event handlers need bus parameter

7. Rendering
   OLD: GlStateManager methods
   NEW: RenderSystem methods
   Impact: ~6 method call replacements

8. Build System
   OLD: ForgeGradle 2.3 + Java 1.8
   NEW: NeoForge Gradle 6.x + Java 17+
   Impact: Complete build.gradle rewrite
